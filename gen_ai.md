Notes about learning to use Large Language Models (LLMs) and Generative AI.

# Embeddings

_Embedding_ refers to representing text as a (long) sequence of numbers. This is a lossy representation—that is, you can’t recover the original text from these number sequences, so you usually store both the original text and this numeric representation.[oshi-camp]
