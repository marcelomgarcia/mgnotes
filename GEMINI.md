# Directory Overview

This repository, `mgnotes`, serves as a personal knowledge base for technical topics, primarily focused on system administration and software development. It contains a collection of notes, command-line snippets, and configuration file examples.

# Key Files

*   `README.md`: Provides a general introduction to the repository and includes some quick reference commands for `git` and `openssl`.
*   `databases.md`: Contains notes and commands for working with SQLite, MySQL, and DuckDB. This includes installation, schema inspection, data export, and user management.
*   `linux.md`: A collection of notes on Linux system administration, covering topics like firewall configuration (`ufw`), package cache management (`apt`), user permissions (`umask`), and disk management (`parted`).
*   `debian_post_install.md`: Likely contains a checklist or guide for setting up a new Debian system.
*   `devel.md`: Probably contains notes related to software development.
*   `files/`: This directory stores various configuration file examples, such as for `tmux`.

# Usage

This repository is intended for personal reference. The markdown files can be read directly or viewed in a markdown renderer. The configuration files in the `files/` directory can be used as templates for setting up development tools.
